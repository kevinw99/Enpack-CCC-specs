## Turn Extraction Algorithm

A **Turn** = one user prompt + all assistant messages until the next user prompt.

```
For each message in session:
  - If type=user AND content is plain text (not tool_result): START NEW TURN
  - If type=assistant: ADD to current turn
  - If type=user with tool_result blocks: ADD as tool result to current turn
  - Skip: system, progress, file-history-snapshot
```

**Final text extraction**: Collect text blocks that come AFTER the last `tool_use` block in the turn. This captures the assistant's summary/explanation, not the preamble ("let me look at...").

**Tool summary**: Count tools by name (`Read (3), Write (2)`) + narrative from file paths and Bash `description` field.

**Auto-title**: Use first sentence/60 chars of user prompt. No LLM needed.

**Long prompts** (>500 chars): Show first few lines, then `<details>` collapsible for full text.
