## 核心设计要点

### 1. 云盘目录结构
```

├── 01_内部文档/        # 各部门文档（运营/营销/研发/生产）

```

### 2. AI无人工干预读取方案

**推荐：本地同步 + 索引系统**

```
云盘 → 云盘客户端同步 → 本地目录 → 索引生成器 → 元数据JSON → AI读取
```

- 索引脚本自动扫描文件、提取关键词、生成摘要
- AI通过索引文件快速定位所需文档
- 定时任务保持索引更新

### 3. 文件命名规范
```
[类型代码]-[部门/项目]-[序号]-[描述].[扩展名]
示例: SOP-MA-001-蒸镀作业程序.pdf
```

| 扩展性 | 低（需建新目录） | 高（AI自动适应） |
| 检索能力 | 依赖目录结构 | 基于元数据，更灵活 |
