## 风险与缓解

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|----------|
| LLM 提取质量仍不满意 | 高 | 低 | Phase B 对话验证先确认质量 |

| API 输出格式不稳定 | 中 | 中 | JSON schema 校验 + 重试 |
| PDF 文本仍然乱码 | 低 | 中 | LLM 能根据上下文推断；换 PDF 解析库 |
