## 2. 验收标准评估

### ✅ 标准 1: LLM 提取的参数名简洁准确

**v1 正则问题**: 参数名常为句子片段，如 "蒸发舟蒸发速度约" 而非 "蒸发速度"

**v2 LLM 结果**:

| 参数名 | 值 | 单位 |
|--------|-----|------|
| 蒸发速度 | 0.4~0.5 | g/min·cm² |
| 舟槽深度 | 1~1.2 | mm |
| 新舟加热时间 | 12-15 | 分钟 |
| 最大排气量 | 25 / 35 | Torr·L/s |
| 冷却水流量 | >15.2 | 升/分钟 |

**评估**: ✅ 参数名简洁规范，无冗余文字

---

### ✅ 标准 2: 操作步骤连贯有序

**v1 正则问题**: 步骤可能包含目录条目、重复项、或顺序混乱

**v2 LLM 结果** (蒸发舟操作规范):

```
1. 安装蒸发舟
   1.1 放置位置: 抵住左侧螺柱
   1.2 舟间距: 约3mm
   1.3 螺柱要求: 确保到位

2. 加热程序
   2.1 检查: 真空度达标 10⁻³Pa
   2.2 逐步升温: 15~20min
   2.3 铝液铺展: ≥80%
   ...
```

**评估**: ✅ 步骤分组清晰，层次结构完整，无 TOC 混入

---

### ✅ 标准 3: 设备信息结构化可读

**v1 正则问题**: 设备信息碎片化，同一设备的参数分散在多条记录中

**v2 LLM 结果** (NHS-35 扩散泵):

| 参数 | 值 | 说明 |
|------|-----|------|
| **型号** | NHS-35 | Agilent (安捷伦) |
| **总功率** | 24000W (4000W×6) | Y型或△型连接 |
| **电压** | 380/415V (Y型) 或 400V (△型) | - |
| **最大排气量** | 25 Torr·L/s (正常) / 35 Torr·L/s (@0.01Torr) | - |
| **冷却水流量** | >15.2 升/分钟 | 进水15-26℃ |
| **泵油量** | 11.3 升 | Neovac SY / Invoil 704 |

**评估**: ✅ 同一设备信息完整聚合，表格结构化呈现
