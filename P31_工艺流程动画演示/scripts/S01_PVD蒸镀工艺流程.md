## 场景 1：为什么需要集流体？（30s）

**画面**: 手机 → 电动车 → 电池内部结构放大

**旁白**:
你的手机、电动车里都有锂电池。锂电池内部有正极和负极，中间靠锂离子移动来充放电。但锂离子在正/负极材料里产生的电流需要被**收集起来**，导出到外部电路 — 承担这个角色的薄片叫**集流体**（Current Collector）。

传统做法：正极用一张纯铝箔，负极用一张纯铜箔。

**动画要素**:
- 电池剖面图，标注正极、负极、电解液、集流体
- 电流流动箭头动画
- 传统铝箔/铜箔示意

## 场景 2：复合集流体的三明治结构（30s）

**画面**: 传统金属箔 → 过渡到三明治结构爆炸图

**旁白**:
英联做的不是传统纯金属箔，而是一种**三明治结构**：

```
┌─────────────────────┐
│  铝层（极薄, ~1μm）   │  ← 上面一层金属
├─────────────────────┤
│  塑料薄膜（PET/PP）   │  ← 中间一层塑料
├─────────────────────┤
│  铝层（极薄, ~1μm）   │  ← 下面一层金属
└─────────────────────┘
```

好处：更轻、更便宜、更安全（电池短路时塑料层会熔断，切断电流，防止起火）。

**核心问题**：中间是塑料，两面要镀上极薄的铝层。怎么镀？

**动画要素**:
- 三层结构逐层组装动画
- 厚度对比（传统6-15μm vs 复合1μm）
- 安全机制：短路 → 塑料熔断 → 电流切断的动画

## 场景 3：PVD 蒸镀原理（60s）

**画面**: 真空腔体内部全景 → 逐步放大到蒸发舟

**旁白**:
PVD（Physical Vapor Deposition，物理气相沉积）的原理非常直觉：

1. 把整个设备抽成**真空**（没有空气）
2. 把铝加热到 **1500°C 以上**，铝变成蒸汽（就像水烧开变成水蒸气）
3. 铝蒸汽飘上去，碰到上面经过的塑料薄膜，冷却凝结成固体铝层

就像冬天你对着冷玻璃哈气，水蒸气凝结成水雾一样 — 只是这里是铝蒸汽凝结成铝膜。

**动画要素**:
- 真空腔体横截面视图
- 塑料薄膜连续走过（传送带效果）
- 蒸发舟加热发光 → 铝蒸汽粒子上升 → 沉积到薄膜
- 类比动画：哈气→玻璃凝水

```
塑料薄膜连续走过（像传送带一样）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━→ 走膜方向
  ↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑  铝蒸汽往上飘
  
  🔥  🔥  🔥  🔥  🔥  🔥   ← 一排蒸发舟，每个都在加热熔化铝
```

## 场景 4：蒸发舟细节（40s）

**画面**: 单个蒸发舟放大 → 铝丝送入 → 熔化 → 蒸发

**旁白**:
"舟"就是一个个小的耐高温容器（大约 12cm × 3cm），材质是**氮化硼（BN）+ 二硼化钛（TiB₂）** 的陶瓷复合材料，能承受 1700°C。

铝丝（像细铁丝一样的纯铝丝）被机器自动送入舟里 → 舟通电加热 → 铝丝熔化成铝液 → 继续加热铝液蒸发 → 蒸汽沉积到上方的塑料膜上。

标准配置是 **36 个舟（两排各18个）**，并排摆放，覆盖整个薄膜的宽度，保证镀出来的铝层厚度均匀。

**动画要素**:
- 蒸发舟 3D 模型（12cm × 3cm 陶瓷容器）
- 铝丝送入动画（φ1.8mm，450mm/min）
- 熔化过程：固态铝丝 → 液态铝池 → 蒸汽
- 36 个舟的俯视排列图（两排各18个）

## 场景 5：凹凸点缺陷问题（50s）

**画面**: 成品膜面放大 → 显示缺陷 → 三种飞溅机制

**旁白**:
想象一锅滚烫的油 — 如果你往里滴水，油会溅得到处都是。蒸发舟里的情况类似：

1500°C 的铝液在舟里沸腾蒸发，有时候会**溅出小液滴**。这些液滴飞到上面经过的塑料膜上，形成微米级的小凸起或小坑 — 这就是**凹凸点**。

凹凸点意味着表面不平整：影响后续涂布工艺、可能导致电池内部短路、客户检验不合格 → 废品。

**动画要素 — 三种飞溅机制**:

| 机制 | 动画效果 | 类比 |
|------|---------|------|
| 气泡核化破裂 | 铝液面气泡生成→破裂→弹射液滴 | 粥煮沸溅出 |
| 送丝机械冲击 | 铝丝插入液池→冲击波→溅射 | 往油锅里扔东西 |
| 舟间热辐射 | 相邻舟互相辐射→局部过热区域高亮 | 36个火炉挤一起 |

## 场景 6：解决方案（50s）

**画面**: 减舟实验 → 钨网方案

**旁白**:

### 方案一：减舟
减少蒸发舟的数量。从 36 个(18+18) 减到 18 个(9+9)、5个、3个、1个。舟少了，彼此间距大了，热辐射弱了，飞溅就少了。实验证实 9+9 比 18+18 凹凸点降了**10倍**。

矛盾：舟少了产量低，膜厚也可能不均匀。

### 方案二：钨网
一片极细的**钨金属丝编织的网**（200目，孔径约0.074mm），平铺在舟槽里，泡在铝液中。铝液会沿着钨丝的网格均匀铺展开（毛细效应，就像纸巾吸水一样）。铺展均匀了，就不会局部堆积沸腾飞溅。效果：凹凸点降 **95.5%**。

为什么用钨？因为钨的熔点 3422°C，在 1500°C 的铝液里完全不会被腐蚀。

**动画要素**:
- 减舟对比：36舟 vs 18舟的俯视图，热辐射强度颜色变化
- 凹凸点计数柱状图动画（18+18 → 9+9 降10倍）
- 钨网微观结构放大 → 铝液毛细铺展动画
- 对比：无钨网（液滴飞溅）vs 有钨网（均匀液膜）

## 场景 7：质量验证（20s）

**画面**: CCD 检测 → 物性测试 → 合格成品

**旁白**:
生产线上的 CCD 工业相机实时拍摄膜面，自动检测凹凸点。方阻测试确认导电性，剥离力测试确认附着力。所有指标合格，复合集流体才能交付给电池厂。

**动画要素**:
- CCD 相机扫描膜面的动画
- 仪表盘/数据面板：方阻、剥离力、膜厚均匀性
- 最终成品卷膜出厂

## 术语速查表（可作结尾字幕卡或附录）

| 术语 | 含义 |
|------|------|
| PVD | 物理气相沉积，用蒸发方式镀膜 |
| 蒸发舟 | 装铝液的耐高温陶瓷小容器 |
| 凹凸点 | 铝液飞溅造成的膜面缺陷 |
| BN (氮化硼) | 蒸发舟的主要材料 |
| 钨网 | 铺在舟内帮助铝液均匀铺展的金属丝网 |
| 方阻 | 铝层导电性指标（Ω/□） |
| 剥离力 | 铝层与基膜的粘合强度 |
| CCD | 工业相机，实时检测膜面缺陷 |
| 复卷 | 展开重卷，同时检测缺陷 |
| 送丝速度 | 铝丝送入蒸发舟的速度 |
| 冷电阻 | 蒸发舟未加热时的电阻值，反映舟的老化状态 |
