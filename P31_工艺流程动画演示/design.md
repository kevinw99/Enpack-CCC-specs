#### 工具 1：Blender

| 项目 | 信息 |
|------|------|
| **全名** | Blender |
| **当前版本** | 5.1.1 (2026-04-14) |
| **厂商** | Blender Foundation（非营利基金会） |
| **总部** | 荷兰阿姆斯特丹 |
| **赞助商** | NVIDIA, AMD, Apple, Meta, Epic Games 等 |
| **官网** | [blender.org](https://www.blender.org/) |
| **下载** | [blender.org/download](https://www.blender.org/download/) |
| **费用** | 完全免费，GPL 开源许可 |
| **平台** | Windows / macOS (Apple Silicon) / Linux |
| **社区规模** | 全球最大开源 3D 社区，NPS +82 |

**核心功能**：

| 功能模块 | 说明 | P30 用途 |
|---------|------|---------|
| 3D 建模 | 网格、NURBS、布尔运算、雕刻 | 蒸发舟、真空腔体、基膜卷轴模型 |
| Geometry Nodes | 程序化建模，参数驱动 | 三明治结构自动生成（改厚度参数即可重新生成） |
| 粒子系统 | 流体、烟雾、粒子发射模拟 | 铝蒸汽上升、液滴飞溅、气泡破裂 |
| Cycles 渲染 | 物理准确的光线追踪 | 铝的金属反光、PET 半透明、高温发光 |
| EEVEE 渲染 | 实时预览（PBR） | 制作中快速预览，不等渲染 |
| Grease Pencil | 3D 场景中叠加 2D 绘图/标注 | 中文标注（"铝层 ~1μm"）、箭头、温度颜色 |
| 关键帧动画 | 时间轴 + 曲线编辑 | 爆炸图组装、温度变化、设备运动 |
| 视频编辑 (VSE) | 内置剪辑器 | 简单片段拼接 |
| Python API | 完整脚本接口 | 批量渲染、参数化生成（如自动对比 18+18 vs 9+9） |
| CAD 导入 | STEP/IGES（插件） | 导入 ULVAC 设备 CAD 图纸 |

**AI 插件**：

| 插件 | 功能 | 费用 |
|------|------|------|
| Dream Textures | 本地 Stable Diffusion 生成材质纹理 | 免费开源 |
| Blender MCP | Claude AI 辅助建模（自然语言指令） | 免费 |
| AI Material Factory | 文本→PBR 材质（8K） | 付费 |

**硬件要求**：

| 配置 | 最低 | 推荐 |
|------|------|------|
| CPU | 4 核 | 8+ 核 |
| RAM | 8 GB | 32 GB（粒子模拟） |
| GPU | 2 GB VRAM | 8+ GB VRAM（NVIDIA RTX，GPU 渲染快 5-10 倍） |
| macOS | Apple Silicon | M1 Pro/Max 及以上 |

**学习路线**（从零到可用，~4 周）：
1. Week 1：Blender Guru 甜甜圈教程（YouTube 免费，8-10h）
2. Week 2：动画 + 粒子系统（官方教程，8-10h）
3. Week 3：Polygon Runway 工厂动画教程（YouTube 免费，6-8h）
4. Week 4：实战 P30 Pilot

**P30 角色**：**核心制作工具** — 承担所有技术精确场景的 3D 建模、动画、渲染。占总工作量约 50-60%。

| **全名** | Kling AI (可灵) |

| **厂商** | 快手科技 (Kuaishou Technology) |
| **总部** | 中国北京 |

**核心功能**：

| 功能 | 说明 | P30 用途 |
|------|------|---------|
| 文生视频 (Text-to-Video) | 中文提示词→4K视频，最长15秒 | 输入"电动车电池内部结构放大"→概念片段 |
| 图生视频 (Image-to-Video) | 静态图→动态视频 | 把 Blender 渲染的静帧"动起来" |

**限制**：无法精确控制画面中的具体物体尺寸、标注文字、技术参数 — 这就是为什么技术场景必须用 Blender。

**P30 角色**：**AI 概念视觉主力** — 生成开场/结尾、工厂氛围、产品应用等不需要技术精确的概念片段。占总工作量约 10-15%。

## 2. Pilot 计划：场景 2 — 三明治结构

### 2.1 为什么选场景 2

- **最简单**：只有 3 层结构，无复杂物理过程
- **最通用**：这个素材在 S01、S03（产品介绍）中都会复用
- **验证全链路**：虽然简单，但走完 Blender→DaVinci 的完整流程
- **30 秒成品**：投入小，快速验证

### 2.2 Pilot 分镜

```
时间轴（30 秒）：

0s─────5s─────10s─────15s─────20s─────25s─────30s
│      │       │       │       │       │       │
│ 传统 │ 过渡  │ 三层  │ 爆炸  │ 标注  │ 安全  │
│ 铝箔 │ 动画  │ 组装  │ 展开  │ 尺寸  │ 机制  │
```

**帧 1 (0-5s)**：传统纯铝箔 — 一张银色薄片，标注"传统集流体 6-15μm"
**帧 2 (5-10s)**：过渡 — 铝箔变薄，中间裂开，露出塑料层
**帧 3 (10-15s)**：三明治组装 — 三层从上下合拢：铝层(1μm) / PET基膜 / 铝层(1μm)
**帧 4 (15-20s)**：爆炸图展开 — 三层分离，每层旁边标注材质和厚度
**帧 5 (20-25s)**：尺寸对比 — 传统(6-15μm) vs 复合(总厚~6μm，金属仅2μm)
**帧 6 (25-30s)**：安全机制 — 电池短路 → 塑料层熔断 → 电流切断（红色→绿色）

### 2.3 Pilot 执行步骤

| 步骤 | 工具 | 耗时估算 | 产出 |
|------|------|---------|------|
| 1. Blender 建模 | Blender | 2-3h | 三层板材 3D 模型 |
| 2. 材质贴图 | Blender | 1h | 铝质感、PET 半透明、标注文字 |
| 3. 动画关键帧 | Blender | 2-3h | 组装→爆炸→短路 动画 |

### 2.4 Pilot 验收标准

- [ ] 三明治结构 3 层清晰可辨
- [ ] 厚度标注准确（铝层 ~1μm，基膜 ~4μm）
- [ ] 安全机制动画直观可理解
- [ ] 中文标注和旁白清晰
- [ ] Blender 渲染和 Kling 片段风格基本统一
- [ ] 团队评价：比纯文字/静态图 PPT 更有效
