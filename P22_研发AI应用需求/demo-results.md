## N-02: 可行性分析

### 演示场景
评估两种MA复合铝箔蒸镀工艺方案，判断哪个更可行。

### 输入
```
标题: MA复合铝箔蒸镀工艺配方可行性评估
背景: 评估两种蒸镀方案在方阻和凹凸点控制方面的可行性
工艺背景: MA复合铝箔生产线，PVD蒸镀工艺，客户要求方阻20-50mΩ/□

候选方案:
  方案A: 高纯铝+低速蒸镀
    - 铝丝纯度: 99.99%
    - 走膜速度: 8 m/min
    - 蒸镀舟数量: 9
    - 基膜: PET 6μm

  方案B: 标准铝+高速双面蒸镀
    - 铝丝纯度: 99.9%
    - 走膜速度: 15 m/min
    - 蒸镀舟数量: 18
    - 基膜: PET 4.5μm

目标指标:
  - 方阻: 20-50 mΩ/□ (权重0.8)
  - 凹凸点密度: 0-5 个/m² (权重0.9)
  - 结合力: 3-5 级 (权重0.6)
```

### 输出（AI生成）

**方案排序:**

| 排名 | 方案 | 可行性 | 评分 | 置信度 |
|------|------|--------|------|--------|
| 1 | 方案A: 高纯铝+低速蒸镀 | 中 | 0.50 | medium |
| 2 | 方案B: 标准铝+高速双面蒸镀 | 中 | 0.50 | low |

**方案A的技术指标预判:**

| 指标 | 预判范围 | 达标 |
|------|----------|------|
| 方阻 | 15~40 mΩ/□ | 是 |
| 凹凸点密度 | 2~15 个/m² | 否 |
| 结合力 | 3.5~5 级 | 是 |

**AI关键判断:**
- 方案A的方阻和结合力可达标，但**低速蒸镀(8m/min)导致PET基膜受热时间过长，凹凸点超标风险很高**
- 方案B走膜速度过高(15m/min)，**铝沉积量不足，方阻可能超标**，且缺少关键参数(蒸镀功率)
- 两个方案均标注了**知识库缺口**——没有接入KB时，AI如实标记"证据不足"

### 价值
研发在做实验前，先用AI评估方案可行性，避免盲目试验。AI会指出：
1. 每个方案的优势和风险
2. 技术指标预判（能不能达标）
3. 知识库中缺少哪些相关文档需要补充

## N-05: 体系文件审核

### 演示场景
审核一份《来料检验规程》是否符合IATF 16949标准要求。

### 输入
```
文件: 来料检验规程 QP-IQC-001（简化版，含目的/范围/职责/流程/记录5个章节）
标准: IATF 16949:2016
客户特定要求:
  - 供应商来料必须附带出厂检验报告
  - 关键原材料需100%检验
```

### 输出（AI生成）

**审核概览:**

| 指标 | 结果 |
|------|------|
| 审核条款数 | 3 (7.1.5 监视和测量资源、7.5 成文信息、8.6 产品放行) |
| 整体合规评分 | 0% |
| 严重不符合 | 0 |
| 主要不符合 | 3 |

**逐条发现:**

| 条款 | 状态 | 问题 |
|------|------|------|
| 7.1.5 | 部分符合 | 未提及测量设备校准周期、MSA要求 |
| 7.5 | 部分符合 | 未规定供应商需附出厂检验报告、未区分关键原材料 |
| 8.6 | 部分符合 | 流程过于笼统，未明确抽样方案、放行授权 |

**AI给出的具体整改建议（示例 — 7.1.5条款）:**
1. 增加章节"监视和测量资源控制"
2. 规定测量设备必须纳入台账，按周期校准
3. 校准状态必须现场可辨（合格/限用/停用标签）
4. 用于关键原材料检验的测量系统需做MSA分析

### 价值
- 客户审厂前，先用AI对照标准逐条检查文件，**提前发现问题**
- AI给出**具体可操作的修改建议**，质量部可以直接参考整改
- 系统内置10个IATF 16949关键条款，自动根据文件类型匹配适用条款

## N-03: 专利分析

### 演示场景
分析复合集流体领域的5件专利，了解竞争格局和技术趋势。

### 输入
```
分析主题: 复合集流体领域专利分析
专利数据: 5件专利记录（2件宁德时代、1件万向、1件Tesla、1件松下）
关注领域: PVD蒸镀、复合铝箔、集流体
```

### 输出（AI生成）

**申请人排名:**

| 排名 | 申请人 | 专利数 |
|------|--------|--------|
| 1 | 宁德时代 | 2 |
| 2 | 万向一二三 | 1 |
| 3 | Tesla | 1 |
| 4 | 松下 | 1 |

**地域分布:** 中国3件、美国1件、日本1件

**技术功效矩阵:**

| 技术手段 | 技术效果 |
|----------|----------|
| PVD蒸镀+磁控溅射复合工艺 | 降低方阻至30mΩ/□以下 |
| 多舟联动蒸镀+在线膜厚监测 | 蒸镀速度提升50% |
| PI基膜替代PET | 耐温性提升至250℃ |
| 等离子预处理+梯度溅射 | 结合力提升至5级 |
| 水冷辊蒸镀+阶梯升功率 | 良率提升至98% |

**AI关键专利分析（摘要）:**
> 技术路线正从单一工艺向PVD蒸镀与磁控溅射复合方向发展，基材从PET/PP向耐高温PI基膜演进。行业正朝高速、低损伤、高一致性的连续化生产迈进。

**对研发的启示:**
1. 重视基膜选型与表面处理
2. 关注工艺复合与在线监控
3. 强化热管理设计
4. 探索跨领域技术融合

### 价值
- 批量导入专利PDF，AI自动提取结构化信息（申请人、技术方案、效果等）
- 自动生成统计图表（申请人排名、时间趋势、地域分布）
- AI总结**技术发展趋势**和**对我方研发的启示**

## N-04: 项目申报

### 演示场景
评估2项科技政策与恩派克公司的匹配度，看适不适合申报。

### 输入
```
公司: 恩派克新材料科技有限公司
  - 行业: 新能源材料制造
  - 资质: 高新技术企业、ISO 9001、IATF 16949
  - 营收: 5000万-1亿
  - 员工: 200人
  - 研发占比: 8%
  - 专利: 15件
  - 注册地: 江苏省常州市

待评估政策:
  1. 江苏省重点研发计划（最高500万）
  2. 常州市创新创业领军人才引进计划（最高300万）
```

### 输出（AI生成）

**匹配排序:**

| 排名 | 政策 | 匹配度 | 评分 |
|------|------|--------|------|
| 1 | 常州市领军人才引进计划 | 高匹配 | 0.85 |
| 2 | 江苏省重点研发计划 | 高匹配 | 0.70 |

**常州市人才计划的详细分析:**
- 已满足: 常州注册企业 ✓、营收超2000万 ✓、新能源行业 ✓
- 未满足: 引进人才需博士学位 ⚠️、需5年以上经验 ⚠️
- 建议: 筛选符合博士学历的核心技术人才，整理人才引进协议

**江苏省研发计划的详细分析:**
- 已满足: 江苏注册 ✓、研发占比>5% ✓、实施周期<3年 ✓
- 未满足: 需省级以上研发平台 ⚠️、项目负责人需高级职称 ⚠️
- 建议: 尽快申请省级工程技术研究中心

**综合改善方向:**
1. 需有省级以上研发平台
2. 需要博士学位或高级职称人才
3. 需要完善人才引进的证明材料

### 价值
- 把政策条件和公司资质逐条对照，**自动判断匹配度**
- 明确指出**已满足**和**未满足**的条件
- 给出**具体可操作的改善建议**
- 多个政策一起分析时，汇总**共同的改善方向**

## N-01: 文献检索

### 演示场景
搜索"复合集流体PVD蒸镀"相关的最新学术论文。

### 输入
```
主题: composite current collector PVD deposition lithium battery
关键词: composite aluminum foil, current collector, PVD evaporation
数据源: Semantic Scholar
年份: 2022年至今
```

### 输出
系统对接 Semantic Scholar 和 arXiv 的API，自动搜索并去重。然后由 DeepSeek 对每篇论文:
1. 评估与主题的相关性（高度相关/相关/边缘相关）
2. 生成50-100字中文摘要
3. 按相关性排序输出报告

> 注: 演示时 Semantic Scholar API 因请求频率限制返回0条。正式使用需配置API Key，或对接CNKI等国内数据源。

### 价值
- 研发指定关注的主题和关键词，系统**定期自动搜索新文献**
- AI自动**分类和中文摘要**，不用逐篇读英文原文
- 每周/每两周输出文献汇总报告
