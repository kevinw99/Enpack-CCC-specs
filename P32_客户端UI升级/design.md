# Design: P32 客户端UI升级

## 品牌策略：CCC → 集团的演进路径

### 现状

| 实体 | 全称 | Logo | 备注 |
|------|------|------|------|
| 英联股份 (母公司) | 广东英联包装股份有限公司 | `assets/logo.png` (深红 Enpack logo) | 上市公司 002846 |
| 英联 CCC (子公司) | 江苏英联复合集流体有限公司 | 无独立 logo，使用母公司品牌 | 复合铜箔/铝箔，新能源电池 |

英联 CCC 没有独立的公开 logo。从公开资料来看，它直接沿用英联股份的品牌视觉。

### 建议方案：双层品牌架构

当前 UI 服务于 CCC（复合集流体），但长期要扩展到整个英联集团。我建议采用 **"主品牌 + 业务标签"** 的模式：

```
┌──────────────────────────┐
│  [Enpack Logo]           │   ← 始终使用集团 logo（不变的部分）
│                          │
│  ┌────────────────────┐  │
│  │  复合集流体事业部   │  │   ← 可替换的业务标签（变化的部分）
│  │  智能问答系统       │  │
│  └────────────────────┘  │
└──────────────────────────┘
```

**长期扩展时只需替换业务标签：**
- 现在: `复合集流体事业部 · 智能问答系统`
- 未来: `包装事业部 · 智能问答系统`
- 未来: `英联集团 · 智能问答系统`（集团级入口）

### 实现要点

1. **Logo 固定用母公司 Enpack logo** — CCC 没有独立 logo，且母公司 logo 本身就是 "Enpack"，适用于所有子公司
2. **业务标识用配置变量** — `app_config.division_name` 控制显示文字，部署时按环境切换
3. **配色不绑定子公司** — 使用母公司的深红品牌色，所有子公司通用
4. **示例问题按业务定制** — 欢迎页的示例问题通过配置文件区分（CCC 问铜箔/工艺，包装问易开盖/产能）
5. **数据源标签动态显示** — 侧边栏的 "KB + ERP" 根据实际连接的 MCP 服务自动显示

## 设计原则

1. **专业克制** — 制造业 toB 产品，不需要花哨，但要精致
2. **Streamlit 内改造** — 用 custom CSS 最大化定制，不破坏框架
3. **渐进增强** — 分阶段实施，每阶段独立可交付

## 实现方案

### 核心机制：Streamlit Custom CSS

通过 `st.markdown(css, unsafe_allow_html=True)` 注入全局样式。

```python
# app.py 顶部注入
def load_custom_css():
    css_path = Path(__file__).parent / "style.css"
    st.markdown(f"<style>{css_path.read_text()}</style>", unsafe_allow_html=True)
```

### 文件结构

```
源代码/ai-chat-client/
├── app.py              # 主应用（修改）
├── pipeline.py         # 不变
├── style.css           # 新增：全局自定义样式
├── components.py       # 新增：UI 组件（欢迎页、品牌栏等）
└── assets/             # 新增：静态资源
    └── logo.svg        # Logo（或先用 CSS 文字 logo）
```

### 关键 CSS 改造点

1. **侧边栏** — `.css-1d391kg` (Streamlit sidebar) 深色背景、白色文字
2. **聊天气泡** — `.stChatMessage` 圆角卡片、阴影、左右区分
3. **输入框** — `.stChatInput` 圆角、蓝色聚焦边框
4. **整体背景** — `.main` 浅灰背景
5. **标题** — 隐藏 Streamlit 默认 header/footer/menu

## 分阶段计划

### Phase 1: 基础视觉升级 (MVP)
- 注入 custom CSS（配色、背景、字体）
- 品牌 logo 区（CSS 文字 logo）
- 隐藏 Streamlit 默认元素（hamburger menu、footer）
- 聊天气泡样式美化
- 侧边栏深色主题

### Phase 2: 交互增强
- 欢迎页面 + 示例问题卡片（可点击）
- 工具调用 timeline 样式
- 打字机效果（如 Streamlit 支持）
- 响应式微调

### Phase 3: 品牌完善
- 接入正式 logo
- 加载动画
- 历史记录面板
- 使用统计面板

## 风险

| 风险 | 缓解 |
|------|------|
| Streamlit CSS 类名跨版本变化 | 用 `data-testid` 选择器优先，类名做备选 |
| 深度定制超出 Streamlit 能力 | Phase 1 先验证可行性，不行则考虑 Gradio/Next.js |
| Logo 素材缺失 | 已获取母公司 logo，CCC 沿用母公司品牌 |
| 扩展到其他子公司时品牌不一致 | 双层架构：固定 logo + 可配置业务标签，切换零开发量 |
