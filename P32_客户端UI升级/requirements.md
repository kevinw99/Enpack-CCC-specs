# Requirements: P32 客户端UI升级

## Overview

P29 业务AI客户端目前使用 Streamlit 默认样式，界面简陋：无企业 logo、工厂图标代替品牌标识、左侧菜单功能单一外观粗糙。本规格目标是大幅提升客户端的视觉品质和专业感，使其达到可对外演示、可供业务人员日常使用的水准。

## 现状问题

1. **品牌缺失** — 页面标题用 🏭 emoji 代替 logo，无企业视觉识别
2. **侧边栏简陋** — 仅有设置开关和版本号，无导航结构，无品牌元素
3. **主界面单调** — 纯白背景，无色彩体系，聊天气泡无差异化样式
4. **缺少空状态引导** — 首次打开无引导，用户不知道能问什么
5. **响应式不足** — 未针对平板/手机优化
6. **无加载反馈** — spinner 文案单一，长时间查询无进度感

## Objectives

- 建立 Enpack 品牌视觉体系（配色、logo、字体）
- 重设计侧边栏为专业导航面板
- 提升聊天界面的视觉层次和交互体验
- 添加空状态引导和示例问题
- 优化工具调用详情的展示方式

## Scope

### 包含
- Streamlit 自定义 CSS/主题
- Logo 设计或接入（SVG/PNG）
- 侧边栏重构（品牌区 + 导航 + 设置 + 历史）
- 聊天界面样式升级（气泡、头像、排版）
- 空状态/欢迎页面
- 工具调用详情的卡片式重设计
- 基础响应式适配

### 不包含
- 前端框架迁移（保持 Streamlit）
- 后端/pipeline 逻辑变更
- 用户认证/登录界面（未来规格）
- 多语言支持

## Success Criteria

- [ ] 页面有 Enpack 企业 logo，专业感对标主流 SaaS 产品
- [ ] 侧边栏包含品牌区、功能导航、设置面板三层结构
- [ ] 聊天气泡有用户/AI 视觉区分，排版清晰
- [ ] 首次打开有欢迎界面和 3-5 个示例问题
- [ ] 工具调用详情以卡片/timeline 形式展示
- [ ] 在 1920x1080 和 iPad 尺寸下均可正常使用
- [ ] 业务人员（非技术）试用反馈正面

## Constraints & Assumptions

- 保持 Streamlit 框架，通过 `st.markdown` + custom CSS 实现定制化
- Logo 可暂用文字 logo（Enpack AI），后续替换正式 VI 素材
- 配色基于 Enpack 官方 logo 品牌色（深红色系 #8B1A1A）
- 不引入 JavaScript 框架，保持纯 Python 部署简洁性

## Dependencies

- P29 业务AI客户端（基座代码）
- 英联包装品牌素材（logo、配色规范）— 如无则自行设计临时方案
