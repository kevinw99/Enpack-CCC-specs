- 通过 BOS 设计器可导出"业务对象"元数据，包含字段中文描述、类型、关联关系

  ```sql
  SELECT * FROM T_META_OBJECTTYPE    -- 业务对象定义
  SELECT * FROM T_META_TABLE          -- 表定义
  SELECT * FROM T_META_FIELD          -- 字段定义（含 FFIELDNAME_L2 中文名）
  ```
- K/3 WISE (旧版) 有 `ICClassTableInfo`、`ICClassTableField` 等元数据表

**金蝶云社区 / 开发者中心**
- https://vip.kingdee.com — 可下载 BOS 对象文档

### 3. 逆向/自动化生成

金蝶表/字段都有固定命名规则，可用 LLM 批量反推：
- 表前缀：`T_BD_*`(基础数据) `T_SAL_*`(销售) `T_PUR_*`(采购) `T_IM_*`(库存) `T_AP_*`(应付) `T_AR_*`(应收) `T_GL_*`(总账)
- 字段前缀：`F` + 语义（`FNumber` 编码、`FName` 名称、`FDate` 日期、`FAmount` 金额）
- 做法：`information_schema` 导出 DDL → LLM 基于命名规则+少量样本数据生成中文注解
