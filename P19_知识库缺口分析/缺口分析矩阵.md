## 第二轮：缺口分类汇总

### 按缺口类型统计

| 缺口类型 | 说明 | 数量 | 占比 |
|---------|------|------|------|
| **B**（纯数据缺口） | 需要对接ERP/CRM/业务系统 | 23 | 46% |
| **B+C**（数据+能力缺口） | 需要数据对接+分析逻辑 | 12 | 24% |
| **A**（纯内容缺口） | 可通过撰写知识库文档填补 | 5 | 10% |
| **A+B**（内容+数据缺口） | 需要新文档和数据对接 | 5 | 10% |
| **A+C**（内容+能力缺口） | 需要文档+分析逻辑 | 3 | 6% |
| 无缺口（完全覆盖） | 知识库已可回答 | 2 | 4% |

### 按所需数据源统计

| 数据源 | 依赖的问题数 | 当前状态 |
|--------|-----------|---------|
| **ERP**（全模块） | 42 / 52（81%） | 未对接 |
| **CRM** | 15 / 52（29%） | 未对接 |
| **外部市场数据**（期货、行业） | 8 / 52（15%） | 未对接 |
| **知识库**（现有文档） | 24 / 52（46%） | 已通过P20 MCP可用 |
| **研究报告** | 8 / 52（15%） | 已通过P20 MCP可用 |
| **邮件/会议记录** | 3 / 52（6%） | 未对接 |
| **实验数据库** | 2 / 52（4%） | 未对接 |
| **HR系统** | 1 / 52（2%） | 未对接 |

### 核心发现

**ERP是最大瓶颈。** 81%的问题需要ERP数据。知识库独立只能完全回答52个问题中的2个。但有24个问题可以利用知识库内容作为补充背景信息，即使ERP数据是主要来源。
