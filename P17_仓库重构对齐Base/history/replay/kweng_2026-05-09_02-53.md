**Result:**
`CCH` 是一个组合命令，做两件事：

```bash
# 1. CCC — 启动 Claude Code（跳过权限确认，只允许 git/curl/Edit）
alias CCC='claude --allowedTools "Bash(git:*) Bash(curl:*) Edit" --dangerously-skip-permissions --permission-mode bypassPermissions'

# 2. CCH — 调用 CCC，结束后自动扫描会话历史
CCH() {
  CCC "$@"
  local root
  root="$(git rev-parse --show-toplevel 2>/dev/null)"
  if [ -n "$root" ] && [ -d "$root/src/session_history" ]; then
    (cd "$root/src" && python3 -m session_history scan --incremental 2>/dev/null)
  fi
}
```

**效果**：运行 `CCH` 会启动 Claude Code，退出后自动执行 `/history scan`（增量扫描），把本次会话归类到对应的规格/实体目录下。

团队成员把这两段加到 `~/.bashrc` 或 `~/.zshrc` 即可使用。
