## `/history` 命令说明

`/history` 是 **P16 会话历史分类系统** 的入口命令，用于管理和浏览 Claude Code 的会话历史记录。

### 核心功能

Claude Code 每次会话都会生成 JSONL 格式的日志文件。这個工具会：

1. **扫描** — 解析所有会话 JSONL 文件，按实体（规格、源代码、研究、知识库、工具）自动分类
2. **分类** — 通过文件路径（权重 50%）、文本模式（35%）、关键词（15%）三个信号判断会话属于哪个项目
3. **生成回放** — 将原始 JSONL 转成可读的 Markdown 文件（按"用户提问→AI回答"的轮次组织）

### 子命令

| 命令 | 用途 |
|------|------|
| `scan` | 扫描所有会话并分类，`-i` 增量扫描 |
| `list` | 列出所有已分类的会话 |
| `replay <实体>` | 生成某实体的可读回放 |
| `search <关键词>` | 搜索会话内容 |
| `stats` | 显示分类统计 |

### 存储模式

采用**指针存储**，不复制原始数据。分类索引和回放文件存在各实体目录下的 `history/` 中。例如 P16 已经生成了 3 个回放文件：

```
规格/P16_会话历史分类系统/history/replay/
  kweng_2026-02-15_02-40.md
  kweng_2026-02-16_07-42.md
  kweng_2026-02-16_23-44.md
```
