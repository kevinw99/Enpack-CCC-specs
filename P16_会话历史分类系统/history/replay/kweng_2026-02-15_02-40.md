## Context

**Goal**: Detect spec boundaries within a session's turns and generate separate replay files per spec segment, each placed under the correct entity's `history/replay/` directory.

**Assumption**: Spec work within a session is sequential, not interleaving.

```python
class TurnEntityClassifier:
    def classify_turns(self, turns, entities) -> List[Tuple[Entity|None, List[Turn]]]:
        """Group consecutive turns by their primary spec entity.

        Returns list of (entity_or_None, turns) segments.
        """
```

**Classification logic per turn** (check in order):
1. Check `turn.tool_narrative` for entity `path_patterns` (includes legacy aliases)
2. Check `turn.user_prompt` + `turn.assistant_response` for entity `text_patterns`
3. If no match → `None` (unclassified turn)

**Grouping**:
- Consecutive turns with same entity → one segment
- `None` turns get absorbed into the adjacent classified segment (prefer the preceding one; if first turns are None, attach to the following segment)
- This handles "setup" turns that don't reference a specific spec

Only spec entities (EntityType.SPEC) participate in turn-level splitting. Non-spec entities are not relevant here.
