# P25 团队全员会议 — 需求规格

## 概述

建立月度团队全员会议机制，首次会议定于 2026-04-16（周四），时长 2 小时。会议目标：统一愿景认知、展示阶段成果、明确下一步部署计划、建立持续反馈与协作机制。

## 背景

凌邦德智能（LeapBound AI）V1 业务线聚焦英联股份复合集流体（CCC）制造 AI 应用。团队包括：
- **凌邦德侧**：Kevin（CEO/技术负责人）、梁咏芝（AI 工程师 / V1 项目经理）、李桁（资深 AI 工程师）
- **CCC 侧**：吕伟（项目经理）、翁子航（工艺研发）、董淑玉（基础设施）、任健（系统管理）、步绍宁（业务需求）、徐刚（业务需求）、戴启同（供应链）

V1 项目已完成约 30% 进度，知识库框架已建立，MCP 服务（知识库 + ERP）进入可演示阶段。需要通过全员会议让所有成员理解全貌并参与下一阶段工作。

## 需求列表

### R-01 愿景与战略讲解
- 讲解公司愿景：用 AI 赋能传统制造业数字化转型
- 阐述 V1 定位：CCC 作为 AI 落地试验田，验证方法论后复制到其他垂直行业
- 说明"先深后广"策略：先在 CCC 做深做透，再扩展到 EOE 产线和英联总部
- 解释四层应用路线图：知识管理 → 运营分析 → 商业智能 → 数字孪生
- **所有内容使用中文**

### R-02 V1 阶段进展汇报
- 以时间线形式展示 2026 年 2-4 月的关键里程碑：
  - P18：样本问题收集（52 题，覆盖 7 部门）
  - P19：知识库缺口分析（81% 问题需 ERP 数据）
  - P20：知识库 MCP 服务（47 文件 → 1345 语义块，6 个工具）
  - P21：MCP 问答质量评估（MCP 胜率 60%）
  - P22：研发 AI 应用需求（6 个工具原型）
  - P23：ERP MCP 评估准备（28 题测试集）
  - P24：KB 适配问题集（88 题科学评估集）
- 突出"良性循环"：应用 → 发现缺口 → 数据收集 → 持续改进

### R-03 MCP 部署计划讲解
- 解释 MCP（Model Context Protocol）是什么、为什么选择这个架构
- 展示双 MCP 架构：知识库 MCP + ERP MCP（金蝶）
- 讲解前端工具选择：Cursor 和 Claude Desktop
  - **为什么选 Cursor**：在国内可正常使用（Claude Desktop 在中国无法使用），支持切换 DeepSeek/Claude 等多种模型（成本灵活），原生支持 MCP 协议
  - **非技术人员备选**：Cherry Studio（国产开源 AI 客户端，纯对话界面，支持 MCP）、Trae（字节跳动 AI IDE）
- 说明部署路径：本地开发 → 局域网部署 → 生产环境

### R-04 现场演示
- **李桁演示知识库 MCP**：
  - 连接知识库服务，展示语义搜索、文档检索、产品查询等功能
  - 对比有/无 MCP 的回答质量差异
  - 使用 P18 中的实际业务问题做演示
- **梁咏芝演示 ERP MCP**：
  - 连接金蝶 ERP，展示库存查询、物料查询、期货数据分析等功能
  - 展示 AI 如何直接读取 ERP 数据回答业务问题
- 演示环境：Cursor 或 Claude Desktop

### R-05 CCC 团队分工与参与计划
- 明确每个 CCC 成员在 AI 项目中的角色和期望贡献
- 翁子航：提供工艺知识、验证 AI 回答的专业准确性
- 董淑玉：支持网络和硬件基础设施部署
- 任健：支持文档管理和知识库内容维护
- 步绍宁 / 徐刚：提供业务需求和场景定义
- 吕伟：协调 CCC 侧资源和进度
- 定义"下一步行动项"让每位成员有明确的参与路径

### R-06 月度会议模板
- 设计可复用的月度会议模板，包含固定议程结构
- 标准议程：上月回顾 → 演示展示 → 数据/指标更新 → 讨论与反馈 → 下月计划
- 会议时长：2 小时
- 每月中旬召开

### R-07 反馈收集机制
- 会后收集参会人员的反馈和建议
- 记录 CCC 团队对 AI 工具的真实使用感受和需求
- 反馈内容：功能满意度、缺失功能、使用障碍、优先级建议
- 形式：简单的反馈表（可以是共享文档或结构化表单）

### R-08 行动项追踪
- 每次会议产出的行动项需明确：负责人、截止日期、完成标准
- 下次会议开场回顾上月行动项完成情况
- 建立简单的追踪机制（Markdown 表格即可）

### R-09 会议连续性
- 确保月度会议之间的信息连续性
- 每次会议记录存档于 `规格/P25_团队全员会议/` 目录
- 会议纪要模板包含：日期、参会人、议题、决议、行动项
- 前后会议的行动项和议题自然衔接

## 约束条件

- C-01: 所有会议材料使用中文
- C-02: 首次会议 2026-04-16，9:00-11:00，2 小时
- C-03: 演示需在真实环境中可运行（非模拟截图）
- C-04: 材料需适合技术和非技术背景的混合受众
- C-05: 会议机制需轻量化，不增加过多行政负担
